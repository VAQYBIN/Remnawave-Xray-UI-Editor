# Фирменный набор

Знак и изображения для GitHub. Построены на дизайн-системе приложения
(`frontend/src/shared/ui/tokens.css`) — метафора «патчбей»: трафик входит слева
индиго (`--flux`), коммутируется и уходит справа янтарём (`--ember`).

## Файлы

| Файл | Размер | Где использовать |
|---|---|---|
| `mark.svg` | вектор | эталон знака |
| `logo.png` | 2234×498 (@2x) | шапка README на тёмной теме |
| `logo-light.png` | 2234×498 (@2x) | шапка README на светлой теме |
| `avatar.png` | 512×512 | аватар профиля/организации GitHub |
| `social-preview.png` | 1280×640 | Social preview репозитория |

Иконки самого приложения лежат в `frontend/public` и подключены в `index.html`:

| Файл | Размер | Назначение |
|---|---|---|
| `favicon.svg` | вектор | вкладка браузера |
| `apple-touch-icon.png` | 180×180 | плитка iOS (Safari не берёт SVG-иконку) |

`favicon.svg` — не копия `mark.svg`: у него свой оптический размер (дуги 4, кабель 5,
ядро r=11), иначе на 16 px штрихи истончаются до серой каши.

## Как поставить Social preview

`Settings` → `General` → `Social preview` → `Edit` → `Upload an image` →
`docs/brand/social-preview.png`. GitHub принимает PNG/JPG/GIF до 1 МБ; 1280×640
(2:1) — рекомендованный размер, картинка попадает в OG-карточку без обрезки.

## Знак

Сечение коммутационного гнезда: стальные дуги корпуса разомкнуты ровно там, где
проходит кабель, ядро в центре — точка коммутации, залитая градиентом
`flux → ember`. Тот же знак живёт на экране входа (`features/auth/LoginPage.tsx`).

Правила:

- минимальный размер — 16 px (в фавиконе разрывы дуг ещё читаются);
- защитное поле вокруг знака — не меньше радиуса ядра (⅙ ширины);
- знак не перекрашивается: сталь `#6b7789`, кабели `#6e7bff` / `#f0a44a`.
  На светлом фоне используется затемнённая пара `#5560e8` / `#e0902f`;
- вордмарк — JetBrains Mono 700 с кареткой `_` цвета `--flux`, ровно как
  заголовок в приложении. Гротеск (Golos Text) в вордмарке не используется.

## Перегенерация

Разметка всех изображений — в `src/board.html`, снимки снимает Playwright:

```bash
cd frontend && node ../docs/brand/src/render.mjs
```

Размер каждой картинки задаёт бокс её элемента в вёрстке, поэтому
`social-preview.png` выходит ровно 1280×640, а `apple-touch-icon.png` — 180×180
(он единственный пишется не сюда, а в `frontend/public`). Шрифты подтягиваются с
Google Fonts — для рендера нужен интернет. Нужен установленный браузер:
`npx playwright install chromium` из каталога `frontend`.
